MUJI Events -- Event Management & Booking System
MUJI Events is a web-based event management website where users can
browse upcoming events, view event information, book tickets, and manage
event listings.
Features
- Member login -- Sign in with a username and password to access
  the website.
- Dashboard -- View a management overview, including total events,
  registered attendees, total revenue, and ticket sales performance.
- Browse events -- View upcoming events and their details,
  including the event name, date, time, description, and ticket price.
- Search and sort -- Search for events and sort the event list by
  date.
- Book tickets -- Select Book Ticket on an event to add
  tickets to the cart.
- Manage event listings -- Use the edit and delete controls on
  event cards to update or remove an event listing.
- Shopping cart -- Open the cart from the navigation bar to review
  selected tickets.
- Other pages -- Use the navigation bar to visit the Gallery,
  About Us, and Feedback pages.
- Logout -- Sign out of the member area using the Logout option.
Getting Started
1. Open the MUJI Events website in your web browser.
2. On the login page, enter your registered username and password.
3. Select Sign In to enter the website.
4. After signing in, the Dashboard will be displayed.
Use the login details provided by the website administrator or project
owner. Do not share your password.

How to Use the Website
1. View the Dashboard
The Dashboard provides a quick summary of the event management system.
It displays:
- Total Events
- Registered Attendees
- Total Revenue
- Monthly ticket sales performance
Use the navigation bar to move to another section.
2. Browse Upcoming Events
1. Select Events from the navigation bar.
2. Browse the available event cards.
3. Check each event's title, date, time, description, and ticket price.
4. Enter a keyword in the search box to find an event.
5. Use the date sorting dropdown to change the order of the event list.
3. Book an Event Ticket
1. Find the event you want to attend.
2. Review its date, time, description, and ticket price.
3. Select Book Ticket on the event card.
4. Open Cart in the navigation bar to review the selected
   ticket(s).
5. Continue with any booking or checkout steps provided by the website.
Note: The screenshots show the Book Ticket and Cart controls, but do
not show the complete checkout or payment process. Follow the on-screen
instructions if those steps are available.
4. Manage Event Listings
If event-management controls are available to your account:
- Select the Edit (pencil) button on an event card to modify its
  details.
- Select the Delete (trash) button to remove an event listing.
- Use Reset sample events, if displayed, to restore the website's
  sample event listings.
Be careful when deleting an event, as this may remove it from the event
list.
5. Visit Other Sections
- Gallery -- Browse the website's event gallery.
- About Us -- Read information about MUJI Events.
- Feedback -- Visit the feedback section.
The exact content and available actions on these pages depend on the
website implementation.
6. Log Out
When you have finished, select Logout in the navigation bar to leave
the member area.

Requirements
- A modern web browser such as Google Chrome, Microsoft Edge, Firefox,
  or Safari.
- An internet connection if the website uses online resources or a
  hosted server.
- A valid member login, if authentication is enabled.
Notes
- Event availability, dates, times, descriptions, and ticket prices
  may change.
- Check the event details carefully before booking.
- The dashboard figures are management summaries; their accuracy
  depends on the data stored by the website.
- The available booking, payment, attendee-management, and account
  features depend on the implemented version of the website.
